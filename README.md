# V7 Sparkling Drink Landing Page

A responsive landing page for V7 Sparkling Drink built with HTML, CSS, and JavaScript.

## Features
- Dynamic theme switching for different flavors.
- Smooth color, image, and shadow updates.
- Responsive layout.
- Interactive user interface.
- Clean and organized code structure.

## Technologies Used
- HTML5
- CSS3
- JavaScript (DOM Manipulation)

## Purpose
This project was created to practice JavaScript DOM manipulation, dynamic styling, and building interactive landing pages with a clean UI.
